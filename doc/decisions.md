## D：项目主动选择

### D-01 工具链与目录

实际环境 Node 22.15.0、npm 10.9.2、Git 2.39.1.windows.1。采用 npm、ESM、TypeScript NodeNext 解析，源文件相对导入使用 `.js` 扩展以兼容编译后 Node；tsx 执行开发入口，tsc 生成 dist。主配置同时检查源代码、测试和 Vitest 配置，单独 tsconfig.build.json 仅输出生产源代码。

精确锁定 TypeScript 5.9.3、tsx 4.23.15、Vitest 5.0.5、Vite 8.3.5、@types/node 22.15.3；package-lock.json 锁定传递依赖。TS 采用已成熟的 5.9 系列，暂不引入 7.x 编译器迁移；Node 类型与本机 22.15 系列相配。npm registry 元数据确认 Vitest 需要 Node `^22.12.0 || ^24.0.0 || >=26.0.0`，Vite 需要 `^20.19.0 || >=22.12.0`，本机满足两者；Vite 显式列为 Vitest 的 peer 依赖。项目 engines 暂限定已选择的 Node 22（>=22.15），不声称其他主版本已验证。[Vitest 官方迁移说明](https://main.vitest.dev/guide/migration/)亦列出了 5.0 的 Node 下限。

不提前安装 XML 库，也不为历史引入第三方框架。采用用户建议的五个 src 模块；第一轮只有 cli/bootstrap，第二轮新增 domain，第三轮新增 application，infrastructure 留到 IO 轮。examples 第三、四轮加入真实命令脚本。第二至四轮均没有修改依赖或锁文件。

### D-02 对象封装和分派边界

Shape 抽象封装 ID 与可选公共样式；第二轮已落实 move/scale/set、clone 和只读 attributes。Rect/Circle/Ellipse/Line/Text 通过 GeometricShape 与不可变 Geometry 封装各自字段；Group 递归调用同一行为；SvgDocument 管理根、全局 ID 索引与结构操作。SVG 中立元素描述留到 IO 轮，不提前实现。外层仅调用方法或只读视图，不持有可变子数组/字段写权限。ID 在对象生命周期内不可改写。

应用层 CommandDispatcher 是唯一“命令名→命令”的分派点。CLI 分词保留 `{value, quoted}` 等词法信息，解析只负责通用结构；命令特定参数规则随命令实现描述。create 的类型参数解释委托给 domain/ShapeFactory 的唯一“类型名→构造逻辑”映射。读入 SVG 也进入同一个 ShapeFactory，**不在 XML codec 再开一套标签分派表**。

ShapeFactory 接收中立的命名属性对象，不读取 CLI token；第三轮在唯一静态定义中同时提供构造器与位置参数描述，详见 D-08。XML 库对象未来先转成不带行为的传输描述，再通过同一工厂构造。描述只用于边界，不是核心模型。通用遍历交给 Composite；显示使用多态只读描述；写出使用未来的中立元素描述，均不得重复 switch(tag)。根 svg 校验属于文件格式边界，不用于重复分派六种图形类型。

**待重构点**：初期两处集中静态映射允许存在；命令增加或进入插件阶段时改成启动装配的命令构造注册表与 ShapeProvider 注册表，保持唯一查询点。当前不写插件加载器、版本协议、热加载或 box 模板。

### D-03 命令对象与文档快照

第二轮落实图形/文档 clone，第三轮落实候选提交；第四轮已实现以下前后快照、两栈及 init 屏障，见 D-10。read/save/canvas 的屏障与路径/文件原子性仍为规划。下文 deepClone 指概念，实际 API 统一为 clone。

每个成功编辑的历史项保存命令对象、before/after 独立文档快照和成功输出。Command 统一入口，五个编辑类继承 EditCommand；Init 和查询/历史命令直接实现各自行为。未创建无用途的 DocumentCommand/QueryCommand 中间类，不另按名字判断类别。

文档快照由领域对象的 deepClone/专用复制构造完成：

1. 每种具体类复制自己的私有几何、文本、公共样式，保留“属性缺省”和显式值的区别，得到真实类实例。
2. Group 按原 children 顺序递归复制；在挂接复制节点时建立新的父链接，不复制指向旧树的父引用。SvgDocument 创建独立根。
3. 遍历新树重新构建整个 ID 索引，验证全局唯一、父子一致、无环、每个对象只出现一次。索引指向新实例，不序列化旧 Map/指针。
4. 保存尺寸以及未来确实存在的文档元数据；默认路径和历史禁用位归会话，不与文档内容混存。若采用持久 ID 计数器，也必须进入事务状态；优先每次导入扫描求可用 ID，避免全局计数器。
5. 历史快照不得作为活跃文档直接暴露。undo/redo 对目标快照再次克隆并校验，得到可变工作树，防止后续编辑污染历史。

事务策略：先验证参数并准备当前文档的 before/候选副本，命令仅操作候选。所有查找、移动、子树摘挂、数值及结构校验在候选内完成；准备好 after 快照、摘要和新历史状态后，才用一个新的会话状态对象替换当前状态。历史项和 redo 清空都在最后提交点发生。任何异常丢弃候选，当前文档对象、路径、历史两栈和禁用位不动；这比“改到一半再尝试回滚”更容易证明正确。undo/redo 同样先准备恢复结果，再原子替换会话状态与两栈。

read 在临时文档完成 XML 校验、两遍 ID 分配和结构校验，成功提交后才发补 ID 警告。save 先序列化并通过 DocumentStore 执行“写同目录临时文件→替换目标”策略，成功后再提交路径/历史屏障；临时文件清理不得触碰不相关文件。路径更新属于同一命令事务。具体平台替换行为和失败注入测试在 IO 实现轮验证，不承诺抵抗断电的磁盘级事务。终端输出是提交后的通知；stdout 损坏属于会话传输失败，不把已成功编辑重新报告成可回滚的业务失败。

不能仅靠 JSON.parse/stringify：会丢失原型方法、Map、undefined/缺省语义，父链接还会导致循环，无法保证索引指向恢复后的实例。若未来需持久化历史，应设计版本化 memento 格式，并通过同一工厂/领域恢复协议重建，不能把 JSON 普通对象直接当 Shape。

复杂度：令 N 为节点数及文本/属性总大小，H 为历史项数，复制与索引校验 O(N)；第四轮用不可变数组副本准备两栈，额外 O(H)，所以单次编辑/undo/redo 为 O(N+H)，存储最坏 O(HN)，单次临时开销 O(N+H)。适合课程中数十至数百节点、离散 CLI 编辑；暂不硬编码历史容量。出现可测量内存/延迟问题时再考虑链式历史、增量 memento、结构共享及检查点；必须仍一命令一单元，不能静默合并。选快照是为降低复杂结构操作的逆操作遗漏风险，未做性能基准。

### D-04 第二轮领域实现：结构入口与只读视图

SvgDocument 是不带图形 ID 的文档根，既不是 Shape，也不是 Group；它与 Shape 共享内部抽象 TreeNode，仅复用结构维护，不共享图形身份或 move/scale/set API。TreeNode 用 ECMAScript 私有字段保存父链接、有序子节点、文档归属及仅根持有的索引，结构写方法为 protected。对外公开结构写入口仅 SvgDocument 的 insert/remove/reparent，不能调用 Group.addChild 来绕过索引。所有结构操作先准备完整结果再修改链接与索引；不依赖 CLI 预检查。

Group 构造器接受 detached 子树，复制输入数组、验证节点未挂载且互不重复，再建立父链接。离线子树可以暂有重复字符串 ID（它不是文档）；insert 或文档批量构造必须验证所有后代的内部及外部 ID 冲突，失败后整个子树保持 detached。已经挂载的实例不能同时进入另一份文档；显式 remove 后可以转移其独占所有权，clone 则在保留原文档时提供独立副本。

roots/children/style/attributes 返回冻结副本，元素仍是带行为的领域对象。调用对象 move/set 是合法领域行为；修改数组、父级、ID、属性视图无法绕过封装。索引不对外暴露。shape.parent 返回 Group、SvgDocument 或 null；根级图形父级就是文档，detached 子树根的 parent 为 null，后代保留内部父链接。

insert 的 position 是目标父节点当前的插入下标，范围 0..length，默认追加；reparent 的 position 是**从旧父级移除后的最终目标下标**，同父也按此规则计算，默认追加。非法位置先报错，不先摘出节点。跨父重挂接保持子树内部顺序和几何原值；§3 的 group/ungroup/addto 等命令仍未实现，A-01 的跨父分组算法也未实现。

### D-05 第二轮数值、属性与原子变换

项目选择（不是作业新增明文）：坐标允许负数与有限浮点；宽高/半径/stroke-width 允许零、禁止负数及非有限值；画布宽高必须有限且严格大于零。scale 必须有限正数，缩放全部位置与几何尺寸，不缩放 stroke-width 或文本字形。浮点精度遵循 JavaScript number，不额外舍入；结果溢出为 Infinity 时拒绝整个操作，正因子导致极小数下溢为零则接受（图形尺寸允许零）。

ID 必须是非空、非全空白字符串；不改变大小写、不 trim 原值、无公开改 ID 方法。fill/stroke 接受非空字符串，保留原值，不在领域层解析全部 CSS 颜色语法；未提供的样式保持缺省，显式 none/black/0 与缺省有区别。显式 undefined 不是合法 set 值；不增加删除属性 API。text 接受包括空串、换行、中文、空格和 XML 字符在内的原字符串，不转义。DomainError 带稳定 code/message，不打印、不包含终端 error: 前缀。

Geometry 是不可变几何值对象，各具体类通过 x 轴字段、y 轴字段、尺寸字段声明自身白名单；GeometricShape 复用数值计算，所有六类型仍是不同的行为类。Shape 的公共样式 switch(attribute) 仅做属性白名单校验，不是类型名分派。第二轮的唯一 switch(type) 位于 ShapeFactory，第三轮以同位置的私有静态 Map 取代；工厂构造私有候选实例后使用各类 set 再校验输入键，不维护另一套白名单。

move/scale 使用受保护的“预计算→提交”协议：每个叶子先生成并完整验证新 Geometry，Group 收集所有子孙的提交动作；任何后代失败都不执行任何动作。全部准备好后，提交动作只替换私有几何引用，不再验证或调用外部回调。这样保留已有图形实例引用，同时防止“先改第一个孩子、第二个溢出”的部分更新。单字段 set 和画布 resize 同样在赋值前验证全部输入。

### D-06 第二轮 clone 的落地与复杂度修正

六种具体类的 clone 调用自己的构造器，Group 按当前顺序多态克隆孩子；SvgDocument 一次性接收克隆后的根集合并建立全新索引、归属与父链接。没有 JSON 恢复、类型分支链、文件路径或历史栈。副本不共享可变图形/集合；几何值对象也由各类构造器重新生成。

初稿使用“逐根 insert”构建副本，每次复制索引，且每个 Group 构造再次扫描完整后代；在宽树或深树上存在二次复杂度。代码复核后改为文档一次性建索引；Group 初始化只验证直接孩子是互异 detached 根，因为受控单父级不变量已保证它们的后代不能共享。文档挂接仍完整扫描全部后代验证唯一 ID。

令 N 为节点和属性/文本总规模、H 为树高，clone 和组变换均为 O(N) 时间/额外空间，递归调用栈 O(H)；文档查找 Map 平均 O(1)。对已有 M 节点文档插入 K 节点子树，事务准备复制索引，约 O(M+K+同级节点数)；删除类似；reparent 不重建索引，成本为祖先检查与两边兄弟数组复制。课程规模优先简单可证明的原子性，未做性能基准或宣称支持无限深树。

### D-07 第三轮分词和参数边界

Tokenizer 逐字符扫描并返回冻结的 `{value, quoted}`，这个输入契约由 application 声明，domain 不接触 token。空行跳过，忽略行首空白后以 `#` 起始才是注释；命令内部 `#` 原样保留，不支持行尾注释。引号内保留原中文、首尾空格与空串，只把 `\"` 解码成双引号、`\\` 解码成反斜杠；未知转义（包括 `\n`）和尾部悬空反斜杠报词法错误，不默默丢字符。引号外反斜杠为普通字符。`a"b"`、`"a"b`、`"a""b"` 均拒绝，完整引号 token 之间必须有空白；不实现 shell 的片段拼接。

create 只检查参数尾部的未引用 `in`＋目标 token，不搜索文本内容；尾部单独 `in` 报缺少目标。目标本身可以引用，也可以名为 in。所有六类型共用此规则。依据 §4.1 的 `"content"` 写法，项目选择要求 text 内容始终引用，即使没有空格也如此；原文没有明确规定“不含空格文本是否可省引号”，这是可调整的收紧选择，测试已固定，不冒充教师确认。

数值采用完整十进制正则＋有限性检查，支持符号、小数点前/后省略数字（`.5`、`3.`）及科学记数法。拒绝十六进制、单位、空串、引用的首尾空白、NaN/Infinity 和指数溢出；不使用 parseFloat。负坐标与零尺寸遵循 D-05。参数个数由命令/工厂描述校验，多余参数同样失败。保留 A-05 的单参 init 宽度＋默认高度 600。

### D-08 第三轮 Command 和唯一参数来源

本节保留第三轮落地记录；第四轮命令数量和 EditCommand/历史调整以 D-10 为准。

Command 是 execute(session) 的抽象；InitCommand、CreateCommand、TreeCommand、ShowCommand、HelpCommand 保存解析后的意图/参数，实例化后执行真实用例。可变属性输入在构造时复制冻结。各命令静态 parse 负责本命令参数，ArgumentParser 只做通用计数、数值、ID 和描述驱动转换。未单独建立 CommandParser 类：解析入口与具体命令同文件，避免再维护命令名列表；这项调整不改变模块方向。

CommandDispatcher 的单个私有表同时提供命令名分派和 help 清单。只有五个条目有 parse，其他十四个只有说明并明确报尚未实现，没有空命令类。create/tree/show 在解析参数前做无文档守卫；未知命令与已知未实现命令分别报错；help/init 无需当前文档。未增加 exit/quit。

ShapeFactory 的单个静态定义表把每类型的构造函数和中立参数描述放在一起，统一提供 create/describe/descriptions；描述只有参数名、领域属性名、number/text/paint 和是否可选。ArgumentParser 通用转换 w/h→width/height、content→text，并通过描述识别 line 的可选 stroke；help 复用同一描述生成六种语法。原 create(type,id,attributes) API 及其回归测试保留。没有第二份类型表、CLI token 依赖或动态插件注册 API；后续注册协议仍见 F-01。

### D-09 第三轮候选提交与多态查询

本节保留第三轮会话设计；第四轮统一编辑入口与整体 state 提交见 D-10。

EditorSession 私有持有唯一活动文档。create 克隆当前文档，在候选中构造并 insert，准备冻结的结果摘要后才替换活动引用；任何解析/几何/ID/父级错误都丢弃候选。init 先构造并验证新文档，失败时保留旧引用。CLI 在命令返回后输出成功摘要。当前无路径、两栈或禁用位，因此只验证当前文档与图形状态的原子性；第四轮须把历史状态纳入同一提交边界，不能另在输出阶段追加记录。

查询不暴露活动模型：Shape.describe 通过各类多态 geometryDescription 返回字段、点和文本的中立冻结值；EditorSession 组装不含行为/父对象引用的冻结 TreeView/ShowView；TextPresenter 仅按描述种类和字段格式化，不检查 shape.type 分派。根和普通图形父级以是否具有图形身份区分，根显示 parent=svg。tree 的 rect 摘要用 w/h，show 用领域完整 width/height，布局采用固定两个空格分隔标识与摘要，不动态对齐列。

终端字符串转义由应用层 TextPresenter 承担，使 CLI 只依赖 application 并负责流输出；JSON.stringify 仅用于呈现带引号的字符串，绝不用于模型克隆。原文 text 与 XML 字符仍保存在模型中，XML 转义尚未实现。描述生成与 tree/候选 clone 是 O(N)，create 暂可接受整树复制成本；show 只生成指定节点描述。未来 XML 序列化协议应按实际需要另设计，不能把终端显示字符串当 SVG。

### D-10 第四轮编辑与历史落地

EditCommand 将 execute 固定委托 EditorSession.executeEdit，具体 Create/Move/Scale/Set/DeleteCommand 的 apply 仅操作候选文档。替代第三轮会话专用 create 方法，防止每种编辑重复事务步骤。SetCommand 按 Shape.attributeKind 转换数值；几何和文本字段从 ownAttributes 的多态结果获得，公共样式包括缺省项，不建立类型分支。当前 ownAttributes 与可编辑字段一致；未来若增加只读派生属性，必须同时调整该契约，不能自动允许 set。

HistoryEntry 对 before/after 各自 clone；恢复再 clone。命令对象用于保留意图，不用于重做计算，避免逆运算浮点误差或副作用重复执行。HistoryManager 的 record/undo/redo 返回新对象或准备好的迁移值，不原地 pop/push 活动两栈。EditorSession 私有 state 同时持有文档和历史，所有可能抛错的候选执行、快照和历史准备都在替换 state 前完成；测试注入晚期失败验证此边界。

成功 init 建新空文档、清栈并禁用；下一成功编辑解禁；失败 init/编辑不改变已有文档和历史。undo 到空栈仍为普通空栈，不重新禁用。一条成功编辑一个单元，包括几何不变、set 同值和空组；失败编辑/查询不清 redo。没有文件路径/默认路径状态，后续 IO 不得绕开整体提交。

成功摘要采用 move by、scale by、updated、deleted；undo 输出 undone: 命令意图，redo 输出原成功摘要。作业明确要求的是摘要及错误格式，未声称这些摘要逐字等于示例。set 文本可接受单个未引用 token，空格/空串仍需引号；create text 沿用 D-07 的引用要求。模型不做 XML 转义，未引入新依赖。过程和逐功能提交见 [round4.md](round4.md)。

## A：原文未明确的暂定事项

### A-01 跨父 group 的新父级、插入位置及顺序

**原文**：§3 要求从各自父容器摘出且保持相对顺序，§4.2 禁止同时包含某容器及其子孙；没有规定跨父时的位置算法。

**推荐**：先拒绝重复选择和祖先/后代混选。选择节点共享父级时，新组放到最早被选节点原位置，组内按原兄弟顺序（不按命令参数顺序）。跨父时，新父级取被选节点的最近共同祖先容器（必要时为文档根）；用修改前全树的深度优先先序确定子节点顺序，新组插在该共同祖先中最早含有被选节点的直接子分支之前。若该分支本身就是被选节点，则替换它的原位置；未选择的祖先即便变空也保留。

**例子**：根下顺序 A[g:a1,a2]、B[g:b1,b2]，执行 `group x b2 a2`，暂定根变为 x[a2,b2]、A[a1]、B[b1]。这让顺序确定且不依赖参数排列；跨父重组不可避免可能改变与未选择节点的视觉重叠关系，原文未承诺完全保持 z-order。

**待验证**：教师是否要求统一放根、按输入顺序或另一插入算法。验收用同父非连续节点、跨父不同深度、空祖先、参数倒序和非法祖先组合；实现前固定期望。此决策只在结构方法中落实，不散落到命令里。

### A-02 历史禁用、旧历史保留和清空

**原文**：§4.3 明确文档操作后禁用、下一编辑解禁，但没有说旧历史保留还是清空。

**推荐**：成功 init/read/save/修改 canvas 都建立新的历史边界：清空 undo/redo 并设禁用位。下一成功编辑以当前文档为 before 创建第一条新历史并解禁；撤销它只能回到边界，不跨回旧文档。失败命令不改两栈/标志。canvas 查询无副作用。显式禁用位仍有必要，以区别“普通空栈”与指定的 IO 后禁用错误。

**理由**：保留旧快照然后解禁，可能跨 read 恢复另一文件或撤销回 save 前状态；清空使会话与文件边界容易解释并释放内存，但这是本项目选择，不是原文强制。

**待验证**：教师是否希望 save 后保留并重新开放旧历史。用“编辑→save→新编辑→连续 undo”确认预期；若要求保留，必须分清文档世代和路径，不可直接沿用不加限制的全局历史。

**第四轮状态**：上述清栈/禁用/解禁选择已在 init 及五个编辑命令中落实并测试；read/save/canvas 尚未实现，相关教师歧义仍未获确认。

### A-03 外部 SVG 的 transform、额外属性和未知元素

**原文**：§0.1 展示 transform 以及 font-size/text-anchor；§3 要求 read SVG，但未完整定义支持范围。§4.1 白名单约束 set，不足以推导“导入必须拒绝一切额外属性”。

**推荐**：先保证编辑器自身六类型输出完整读回。对于 transform、未知图形（path/use 等）、嵌套 svg、影响外观的额外属性（style、font-size、text-anchor 等）先明确拒绝整次导入，报告具体不支持项，保持旧文档不变，避免悄悄丢数据或错误显示。允许 XML 声明、注释、根 xmlns/width/height/匹配坐标的 viewBox；任意不同原点/缩放的 viewBox 也暂拒绝。对于 §4.4 明说的降级场景，允许 `<g data-kind="box">` 作为普通 g 读入（其后代仍需符合支持子集），发语义降级警告，不加载插件，也不允许 create box；其 data-kind 暂不回写。其他额外属性不静默忽略。

**理由**：任意变换可能使 rect/circle 变成当前模型无法表达的形状，保留原 transform 又直接改几何会混淆坐标语义。严格、可诊断的子集比静默破坏文件更可验证。

**待验证**：这是兼容性假设，并非已被原文允许的裁剪；尤其 §0.1 的第二个 transform 示例暂不能成功读入。教师若要求该示例可读，必须在 IO 轮扩大设计：在领域层加入矩阵与坐标行为，或定义可安全烘焙的变换子集，并测试嵌套、move/scale/重挂接的一致性。不能直接声称已满足所有外部 SVG。未知元素/属性/降级警告的具体错误文本原文未给，将在实现时统一记录。

### A-04 init 后 save 是否建立默认路径

**原文**：§3 仅明确“无参数保存到读入时的路径”，未说明 init 后显式 save、read 后另存是否更新默认路径。

**推荐**：维护“当前成功关联路径”：read 成功设置；init 成功清空；显式 save 成功更新，无参 save 使用该路径；没有路径时要求传参；任何失败不更新路径。read A→save B→save 暂定写 B；init→save B→save 也写 B。

**理由**：符合常见文档保存体验，避免初次保存后每次仍要传路径。但比原文“读入路径”更宽，需要确认。

**待验证**：教师是否要求固定 read 路径不受 save as 改变；路径采用解析后的绝对路径存储、保留用户输入用于反馈的细节也要测试。

### A-05 其他非阻塞语义

暂定 init 单个参数为宽度、高度默认 600；canvas 修改要求恰好两个数。宽高为正有限数；图形宽高/半径/stroke-width 非负有限数；坐标允许负数与浮点；scale 必须正有限数。不接受 NaN/Infinity。数值合法范围、单参数 init 原文未详述。

help 无需文档（§6 的启动提示支持这个用法），其余依赖文档的命令才执行无文档守卫。空行跳过；去除行首空白后以 # 开头视为整行注释，不支持行尾注释。分词保留引号来源；`in` 子句仅识别尾部未引用 token。第三轮已落实这些选择，转义和相邻片段规则见 D-07；其余尚未实现命令的历史与 IO 行为仍待后续验证。

g 的 set 公共属性只改组自身，借 SVG 继承呈现，不手工改写后代；scale 只处理几何，不缩放 stroke-width 或文本字形大小（text 白名单没有 font-size）。front 对应数组末端（最后绘制），back 对应首端。重复 group 参数拒绝；选一个节点的 group 允许；已在最前/最后的成功顺序命令仍计一个撤销单元、仍清空 redo，遵守“一条成功编辑一个单元”。普通空栈报 `error: nothing to undo` / `error: nothing to redo`，禁用标志优先；show 根级父标签用 `parent=svg`。上述未在原文明定的输出/范围均待测试或反馈校准。
